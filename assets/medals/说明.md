# assets/medals 勋章说明

FlintHub 勋章插件（plugins/medal）的预置勋章图库。10 枚勋章均为手写 SVG（128×128 画布、默认 17×17 渲染），
统一采用「径向渐变圆底 + 白色图形 + 双圈描边 + 顶部绶带弧」模板，风格一致、体积轻量（每枚约 150 字节）。

## 使用方式

- 后台「勋章管理」新增/编辑勋章时，「图片文件名」填 `medalX.svg`（放本目录即可，勿放 uploads，避免孤儿附件清理误删）；
- 不填图片时插件会退回 FontAwesome 图标 + 自定义色（`icon`/`color` 字段），两种方案可混用；
- 显示尺寸：勋章中心页 50×50、后台列表 30×30（CSS 覆盖），其余展示位按 SVG 默认 17×17。

## 设计评价（可改进点）

**优点**：模板统一、配色语义化、SVG 轻量。

**问题**：
1. **小尺寸可读性差**：viewBox 128 但默认渲染 17px，皇冠尖/时钟指针/鸟翅等细节在 17px 下模糊，仅中心页/后台有放大；
2. **语义模糊**：medal3（鸟）、medal4（山）、medal9（V）第一眼不易识别，勋章应"一眼懂"；
3. **形状重复**：medal1/medal6 同为五角星，medal2/medal10 同为爱心，同屏易雷同；
4. **金色系过密**：medal6/7/8 均为金/琥珀，色相区分度低。

**改进建议（按性价比排序）**：
1. 将默认 `width/height` 提高到 32px，小尺寸下轮廓仍清晰；
2. 换用更"勋章化"的大轮廓图形（盾牌、星月、奖杯、火焰），替换 medal3/4/9 三个模糊图形；
3. medal6 改红色系、medal8 改蓝紫色系，拉开与 medal7 金色系的色相；
4. 若不想维护 SVG，直接走插件的 `icon`（FontAwesome）+ `color` 方案，可读性更好。
