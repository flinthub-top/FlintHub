# SEO 优化（seo）插件说明

> 版本：1.2.0 ｜ 作者：SoSite ｜ 状态：✅ 已启用
> 功能：搜索引擎优化插件，支持自定义 Meta 标签、Open Graph、JSON-LD 结构化数据、站点地图、robots.txt

---

## 一、功能简介

- **后台设置页**：自定义站点标题/描述/关键词，配置 Open Graph 与 JSON-LD
- **全局 head 注入**：`layout_head_end` 输出 `<meta>`、OG 标签、JSON-LD 结构化数据
- **站点地图**：`/sitemap.xml` 自动生成（首页/论坛/博客/版块/帖子/博客条目，含 lastmod）
- **robots.txt**：`/robots.txt` 输出爬虫规则（屏蔽后台/API/登录等敏感路径 + Sitemap 指向）
- 设置存 `settings` 表（键前缀 `seo_`），无独立数据表

## 二、目录结构

```
plugins/seo/
├── plugin.json              # 插件清单（hooks: init_after / route_register / admin_route_register / admin_sidebar_links / layout_head_end）
├── Plugin.php               # 生命周期 + 设置读写（getSetting/saveSetting，键前缀 seo_）
├── AdminController.php      # 后台设置页（index/save，继承 Admin\BaseController）
├── FrontController.php      # 前台输出（sitemap/robots）
├── hook/
│   ├── init_after.php       # 初始化（历史性能坑：勿每请求写默认值）
│   ├── route_register.php   # 前台路由（/sitemap.xml /robots.txt）
│   ├── admin_route_register.php  # 后台路由（/seo /seo/save）
│   ├── admin_sidebar_links.php   # 后台侧边栏"SEO 设置"入口
│   └── layout_head_end.php  # 全局 head 注入 meta/OG/JSON-LD
├── assets/style.css         # 后台设置页样式
└── views/admin.php          # 后台设置视图
```

## 三、数据表

无独立表（配置存 `settings` 表，键前缀 `seo_`，如 `seo_title` / `seo_description` / `seo_keywords` / `seo_enable_og` / `seo_enable_jsonld` / `seo_site_url` / `seo_enable_sitemap`）。

## 四、Hooks

| Hook | 用途 |
|---|---|
| `init_after` | 初始化（**注意性能**：勿每请求写默认配置） |
| `route_register` | 前台路由（/sitemap.xml、/robots.txt） |
| `admin_route_register` | 后台路由（/seo、/seo/save） |
| `admin_sidebar_links` | 后台侧边栏"SEO 设置"入口 |
| `layout_head_end` | 全站 head 注入 meta/OG/JSON-LD |

## 五、路由

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/sitemap.xml` | XML 站点地图（最近 1000 帖子 + 500 博客 + 版块，含 lastmod W3C 格式） |
| GET | `/robots.txt` | 爬虫规则（Disallow 敏感路径 + Sitemap 声明） |
| GET | `/seo` | 后台设置页 |
| POST | `/seo/save` | 保存设置（CSRF） |

## 六、注意事项

- **性能坑（历史事故）**：`init_after` 曾每请求调用 `Plugin::activate()` 写 4 个空字符串默认值 → 每页 4 次 `Settings::update` → 全表扫描 + 写缓存文件，导致全站性能回退。**修复：默认配置在插件激活时写入 DB，init_after 勿再重复写默认值**
- 站点地图条目数有限制（帖子 1000 / 博客 500），超大站需扩展
- robots.txt 屏蔽路径覆盖：admin/api/login/register/logout/找回密码/消息/个人中心等
- 卸载后 `/sitemap.xml`、`/robots.txt` 路由失效（404），meta 注入消失
