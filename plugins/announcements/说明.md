# 站点公告（announcements）插件说明

> 版本：1.2.0 ｜ 作者：SoSite ｜ 状态：✅ 已启用
> 功能：首页公告系统，支持多条公告、多种颜色样式、独立关闭（普通堆叠 / 上下滚动两种模式）

---

## 一、功能简介

- 在首页/版块页顶部展示站点公告条（`announcements_display` 钩子注入）
- 支持**多条公告**同时展示，每条可独立配置颜色样式
- 两种展示模式（后台可切换）：
  - **普通堆叠模式**：多条公告纵向堆叠，每条右上角有 × 可独立关闭（CSS 动画淡出）
  - **滚动模式**：多条公告轮播显示（4 秒切换）
- 每条公告可附带跳转链接（`url` 字段，新窗口打开）

## 二、目录结构

```
plugins/announcements/
├── plugin.json              # 插件清单（hooks: init_after / announcements_display / admin_route_register / admin_sidebar_links）
├── Plugin.php               # 生命周期 + 建表 + 查询辅助（getAll / getStyles）
├── AdminController.php      # 后台管理（列表/新增/编辑/删除/切换模式）
├── hook/
│   ├── init_after.php       # 建表 + 一次性字段迁移（url 字段升级兼容）
│   ├── announcements_display.php  # 前台公告条输出（两种模式）
│   ├── admin_route_register.php   # 后台路由注册
│   └── admin_sidebar_links.php    # 后台侧边栏入口
├── assets/style.css         # 公告条样式（颜色变量）
└── views/admin.php          # 后台管理视图
```

## 三、数据表

| 表 | 用途 |
|---|---|
| `announcements` | 公告记录（id / content / url / sort_order / status / created_at） |

- 建表：`init_after` 钩子检测启用后调用 `Plugin::activate()` 幂等建表
- 迁移：首次启用自动补充 `url` 字段（`_announcements_migrated` 标记，仅执行一次）

## 四、Hooks

| Hook | 用途 |
|---|---|
| `init_after` | 建表 + 字段迁移 |
| `announcements_display` | 前台输出公告条（首页 + 版块页两处触发） |
| `admin_route_register` | 后台路由（/admin/announcements 等） |
| `admin_sidebar_links` | 后台侧边栏"公告管理"入口 |

## 五、路由（后台）

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/admin/announcements` | 公告列表 + 管理页 |
| POST | `/admin/announcements/add` | 新增公告 |
| POST | `/admin/announcements/edit` | 编辑公告 |
| POST | `/admin/announcements/delete` | 删除公告 |
| POST | `/admin/announcements/set-mode` | 切换展示模式（normal / scroll） |

## 六、使用说明

1. 后台"扩展 → 公告管理"添加公告（内容支持富文本、可选跳转 URL）
2. 公告样式（背景色/边框色/文字色）由 `getStyles()` 预置多套，后台选择
3. 展示模式在后台切换：普通堆叠 / 上下滚动
4. 前台关闭公告：普通模式下点 × 仅隐藏当前公告条（前端 dismiss 动画，不持久化）

## 七、注意事项

- 公告内容经 `Content::decode()` 解码 + `htmlspecialchars` 转义后输出（防 XSS）
- 关闭按钮为前端行为（`dismissAnnouncement`），刷新后公告重新显示
- 切换滚动模式依赖 `announcementScroll` 容器，少于 2 条公告不启动轮播
