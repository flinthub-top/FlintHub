# 每日签到（daily_checkin）插件说明

> 版本：1.0.0 ｜ 作者：SoSite ｜ 状态：⏸️ 停用（默认未启用）
> 功能：用户每日签到获取积分，支持连续签到奖励（连签天数加成）

---

## 一、功能简介

- 用户每日可签到一次，签到获得基础积分（`checkin_points_base`，默认 2）
- **连续签到奖励**：连续签到天数加成（`checkin_points_bonus`，默认 1/天）
- 数据表 `UNIQUE(user_id, checkin_date)` 天然去重，一天只能签一次
- 签到入口：前台导航"应用"下拉 + 用户下拉菜单（nav_user_menu_items）

## 三、数据表

| 表 | 用途 |
|---|---|
| `daily_checkin` | 签到记录（user_id / checkin_date / points / consecutive_days / created_at，UNIQUE(user_id, checkin_date)） |

- `activate()` 建表 + 确保 `users.points` 字段存在 + 写入默认奖励配置（settings 表）
- `uninstall()` 删除表
- 卸载后 `users.points` 字段**保留**（不删除，防误删其他积分逻辑）

## 四、Hooks

| Hook | 用途 |
|---|---|
| `init_after` | 懒建表 + 迁移 |
| `route_register` | 前台路由（/checkin） |
| `controller_view_before` | 签到状态注入视图 |
| `nav_plugin_links` | "应用"下拉签到入口 |
| `nav_user_menu_items` | 用户菜单入口（当前文件已禁用） |

## 五、路由

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/checkin` | 签到页面（含今日状态/连续天数/累计积分） |
| POST | `/checkin` | 执行签到（返回 JSON：成功/已签到/积分） |

## 六、核心逻辑（doCheckin）

1. 校验登录 + CSRF
2. 查今日是否已签（`UNIQUE(user_id, checkin_date)` + 前置查询）→ 已签返回提示
3. 计算连续天数：昨日有签 → 连续 +1；否则重置为 1
4. 写入签到记录 → `Points::award` 发放积分（基础 + 连签加成）
5. 返回 JSON 结果

## 七、注意事项

- 签到记录按 `checkin_date VARCHAR(10)`（Y-m-d）去重，跨时区以服务器日期为准
- 连续天数判断依赖昨日记录，跨天未签则断签重置
- 入口 `nav_user_menu_items` 文件当前为空实现（作者禁用），实际入口走"应用"下拉
