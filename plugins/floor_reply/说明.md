# 楼中楼（floor_reply）插件说明

> 版本：1.0.0 ｜ 作者：FlintHub ｜ 状态：✅ 已启用
> 功能：在帖子楼层（posts）下方支持对楼层的再回复（楼中楼），支持 @ 提及用户（高亮 + 跳转个人主页）

---

## 一、功能简介

- **楼中楼**：对某条回复（楼层）进行再回复，数据存独立库，**不占用核心楼层数**
- **@ 提及**：回复时 @ 指定用户（`mention_user_id`，0 = 无 @），前端高亮显示，点击跳转其个人主页
- **回复计数联动**：回复成功后同步更新帖子的回复数与最后回复时间（`Thread::incrementReplyCount`）
- **积分奖励**：回复成功触发核心积分奖励（`Points::markReplied` / `Points::award`），并计入站点统计

## 二、目录结构

```
plugins/floor_reply/
├── plugin.json              # 插件清单（init_after / route_register / layout_head_end / post_operation_after / controller_view_before）
├── Plugin.php               # 独立库连接 + 建表 + 楼中楼统计/计数方法
├── FrontController.php      # 楼中楼回复 / 列表接口
├── hook/
│   ├── init_after.php               # 幂等建表兜底
│   ├── route_register.php           # 前台路由（回复/列表）
│   ├── layout_head_end.php          # 注入楼中楼 CSS/JS
│   ├── post_operation_after.php     # 楼层下注入"楼中楼"入口
│   └── controller_view_before.php   # 一次性注入该帖全部楼中楼数据
├── views/list.php           # 楼中楼列表局部模板
└── lang/                    # zh.php / en.php / zh_tw.php
```

## 三、数据表（插件独立库 `plugins/floor_reply/data/floor_reply.sqlite`）

| 表 | 用途 |
|---|---|
| `fr_replies` | 楼中楼回复（post_id / thread_id / user_id / mention_user_id / content / created_at，索引 idx_fr_post、idx_fr_thread） |

- 建表：`activate()` + `init_after` 双保险（幂等 DDL）
- 卸载：`uninstall()` 删表（会清空全部楼中楼数据，请谨慎）

## 四、路由

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/floor-reply` | 提交楼中楼回复（CSRF + 频控） |
| GET | `/floor-reply/list` | 某楼层楼中楼列表（分页） |

## 五、安全与规范

- 提交受 **RateLimiter 频控**（3 次 / 30 秒）保护，防刷分漏洞
- 回复内容经 `$this->e()` / `Content` 净化后输出，防 XSS
- 全部 PDO 预处理绑定
- 楼中楼仅占独立库，不写核心帖子表结构，卸载/禁用对核心数据零污染

## 六、注意事项

- 依赖 `controller_view_before` 一次性注入全帖楼中楼数据，避免每楼层一次查询
- 删除楼层（post）时不自动清理其楼中楼（历史遗留记录保留）
- 积分奖励 / 回复计数联动为核心约定，流程调整时需同步 `Plugin.php` 内相关方法
