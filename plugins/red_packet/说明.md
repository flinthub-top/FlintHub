# 积分红包（red_packet）插件说明

> 版本：1.8.0 ｜ 作者：SoSite ｜ 状态：⏸️ 停用（默认未启用）
> 功能：用户消耗积分创建红包，其他用户可以抢，抢到的积分自动加到账户（含过期退款）

---

## 一、功能简介

- **创建红包**：用户消耗积分创建红包，设置总积分与份数
- **抢红包**：其他用户可抢，每次抢到随机金额（`calculatePoints` 按剩余/份数算法分配）
- **防重抢**：`red_packet_claims` 表 UNIQUE(packet_id, user_id) + 事务捕获冲突，一人只能抢一次
- **过期退款**：红包过期未抢完自动退还剩余积分给创建者（`refundExpired`，访问触发懒清理）
- 红包详情页：查看领取记录、剩余金额、过期倒计时

## 三、数据表（2 张）

| 表 | 用途 |
|---|---|
| `red_packets` | 红包（creator_id / total_points / remaining_points / count / remaining_count / expires_at / status，idx_creator / idx_expires） |
| `red_packet_claims` | 领取记录（packet_id / user_id / points / created_at，UNIQUE(packet_id, user_id) 防重抢） |

- 建表：`activate()` + `init_after` 懒建（幂等）
- 卸载：`uninstall()` 删除两张表

## 四、Hooks

| Hook | 用途 |
|---|---|
| `init_after` | 懒建表 + 初始化缓存文件 |
| `route_register` | 前台路由（/redpacket） |
| `nav_plugin_links` | "应用"下拉"积分红包"入口 |

## 五、路由

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/redpacket` | 红包列表（可抢/可创建） |
| POST | `/redpacket/create` | 创建红包 |
| GET | `/redpacket/{id}` | 红包详情 |
| POST | `/redpacket/{id}/grab` | 抢红包（JSON：抢到积分/失败原因） |

## 六、核心逻辑

```php
public function grab()        // 事务内：INSERT claims（UNIQUE 防重）→ 扣减 remaining → 派奖
public function calculatePoints()  // 随机分配：按剩余金额/人数算法
public function refundExpired()    // 扫描过期 active 红包 → 事务退回剩余 → 改状态
```

## 七、注意事项

- **防重抢**：`UNIQUE(packet_id, user_id)` 唯一约束，INSERT 捕获 Duplicate entry → "你已经抢过了"
- 抢红包在**事务**内完成（begin → 校验 → 扣减 → 记录 → commit），异常 rollback
- 过期退款为**访问触发懒清理**（grab 前或列表页触发 `refundExpired`），无需 cron
- 卸载删表会丢失红包与领取记录，请谨慎
