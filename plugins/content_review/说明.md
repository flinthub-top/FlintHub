# 内容审核（content_review）插件说明

> 版本：2.0.0 ｜ 作者：SoSite ｜ 状态：⏸️ 未启用（注册后需后台启用）
> 功能：发帖、回帖、上传头像、新用户注册审核 + 审核通知，支持后台统一管理、批量操作、免审用户组

---

## 一、功能简介

- **多对象审核**：主题（thread）、回复（post）、头像（avatar）、注册（register）四类目标可独立开关审核
- **审核流程**：内容提交后生成待审记录 → 管理员后台通过/驳回 → 通过后内容对普通用户可见
- **批量操作**：批量通过 / 批量驳回 / 批量删除待审记录
- **免审机制**：按**用户组**白名单免审（管理员组默认免审），免审内容直接放行
- **通知系统**：审核状态变化写入 `review_notifications`，用户前台"审核通知"入口查看（未读徽标，Session 缓存 30 秒）
- **分版块控制**：可仅对指定版块开启审核（`isThreadReviewRequired` 按分类判断）

## 三、数据表

| 表 | 用途 |
|---|---|
| `content_reviews` | 审核记录（target_type / target_id / user_id / status[pending|approved|rejected] / reviewed_at） |
| `review_notifications` | 审核通知（user_id / review_id / type / title / link / is_read） |

- 建表：`activate()` + `init_after` 钩子双保险（幂等 CREATE TABLE IF NOT EXISTS）
- 卸载：`uninstall()` 删除两张表

## 四、Hooks（12 个）

| Hook | 用途 |
|---|---|
| `init_after` | 懒建表（表不存在时） |
| `route_register` | 前台路由（/review-notifications） |
| `admin_route_register` | 后台路由（/admin/content-review 等） |
| `admin_sidebar_links` | 后台侧边栏"内容审核"入口 |
| `thread_create_after` | 发帖后创建待审记录 + 通知 |
| `post_create_after` | 回帖后创建待审记录 |
| `auth_register_after` | 注册后创建待审记录 |
| `avatar_upload_after` | 头像上传后创建待审记录 |
| `controller_view_before` | 待审内容对非管理员隐藏显示 |
| `nav_user_menu_items` | 用户下拉菜单"审核通知"入口（未读徽标） |
| `nav_main_links` | 顶部导航入口（已转移至用户菜单，文件保留空实现） |
| `layout_head_end` | 注入审核相关 CSS |

## 五、核心 API（Plugin.php）

| 方法 | 说明 |
|---|---|
| `createReview($type, $targetId, $userId)` | 创建审核记录（幂等：pending 中不重复） |
| `approve($reviewId)` / `reject($reviewId)` | 通过/驳回（通过后目标内容恢复可见） |
| `batchApprove/batchReject/batchDelete` | 批量操作 |
| `isThreadReviewRequired($categoryId)` | 该版块是否需审核 |
| `isUserExempt($userId)` / `isGroupExempt($groupId)` | 免审判断 |
| `getConfig/saveConfig` | 审核设置读写（settings 表，键前缀 `cr_`） |
| `getUnreadCount($userId)` | 未读通知数（用户菜单徽标） |

## 六、路由

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/admin/content-review` | 后台审核列表（待审/已审） |
| POST | `/admin/content-review/approve` | 通过 |
| POST | `/admin/content-review/reject` | 驳回 |
| POST | `/admin/content-review/settings` | 保存审核设置 |
| POST | `/admin/content-review/delete` / `batch-delete` / `batch-approve` / `batch-reject` | 删除/批量操作 |
| GET | `/review-notifications` | 前台审核通知列表 |

## 七、使用说明

1. 后台启用插件 → 自动建表
2. 后台"内容审核"设置页配置：哪些对象审核（帖子/回复/头像/注册）、哪些版块审核、免审用户组
3. 待审内容提交后，普通用户看到"审核中"提示（controller_view_before 控制），管理员后台审核
4. 被审核用户收到站内通知（用户菜单"审核通知"查看）

## 八、注意事项

- **需与发帖/回帖流程联动**：审核不隐藏原内容（仅标记待审），通过 `controller_view_before` 对非管理员隐藏
- 免审判断优先：免审用户组命中则直接放行，不再创建审核记录
- 通知有 30 秒 Session 缓存（`_cr_unread_{uid}`），避免每请求 COUNT 查询
- 卸载会删除审核记录与通知数据，请谨慎操作
